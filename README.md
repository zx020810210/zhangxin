# zhangxin

一个单机网页版 Word 格式转换工具：

- 上传**模板文档**（.docx）和**待转换文档**（.docx）。
- 根据模板同步目标文档的排版样式，包括字体、字号、行间距、页眉页脚、页码相关分节设置、表格样式以及图表标题编号相关配置。
- 全部处理在浏览器本地完成，不上传文档。

## 使用方式

1. 直接双击 `index.html` 或使用本地静态服务器打开。
2. 分别选择模板和待转换文档。
3. 查看页面中的“模板格式识别结果（文字说明）”，确认模板中已识别到的字体、行距、页面和页码等规则。
4. 勾选需要同步的格式项后，点击“开始转换并下载”。

## 技术说明

工具内置本地 `JSZip` 脚本并在浏览器端直接处理 `.docx`（Open XML 压缩包）中的关键 XML 文件，通过“样式文件替换 + 分节设置同步”的方式尽量保持正文内容不变并统一版式。
